================================================================================
  METHOD 1 — EASIEST (Recommended)
================================================================================

Step 1) First time only — setup
   Open PowerShell and run:

   cd F:\KaamSetu
   .\scripts\setup.ps1

   This will:
   - Create .env files (if missing)
   - Create Python venv in backend\venv
   - Install backend packages (pip)
   - Run database migrations
   - Install frontend packages (npm install)

Step 2) Run both servers
   cd F:\KaamSetu
   .\scripts\run-dev.ps1

   Two new PowerShell windows will open:
   - Window 1 = Backend  (port 8000)
   - Window 2 = Frontend (port 5173)

Step 3) Open browser
   http://localhost:5173

================================================================================
  COMMON PROBLEMS
================================================================================

1) Port 8000 already in use (backend)
   - Close old Django window, or kill process on port 8000
   - Then run backend again

2) Port 5173 already in use (frontend)
   - Close old npm/vite window
   - Then run: npm run dev

3) Backend changes not applied
   - Stop backend (Ctrl+C) and start again:
     python manage.py runserver 8000

4) .env / email OTP not working
   - Check F:\KaamSetu\.env (Gmail SMTP settings)
   - Restart backend after editing .env

5) npm not found
   - Install Node.js from https://nodejs.org
   - Restart PowerShell

6) npm error: "running scripts is disabled on this system" (PowerShell)
   FIX A — Use cmd instead of npm in PowerShell:
     cd F:\KaamSetu\frontend
     npm.cmd install
     npm.cmd run dev

   FIX B — Allow scripts for your user (one time, then npm works normally):
     Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
     (Type Y and press Enter when asked)
     Then: npm install && npm run dev

   FIX C — Open "Command Prompt" (cmd.exe) instead of PowerShell:
     cd F:\KaamSetu\frontend
     npm install
     npm run dev
