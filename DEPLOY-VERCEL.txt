================================================================================
  KaamSetu — Live URLs (kaamsetu.app)
================================================================================

PRODUCTION URLS
---------------
  Website (Vercel):   https://kaamsetu.app
  API (Render):       https://api.kaamsetu.app/api

  www.kaamsetu.app  →  redirects to  kaamsetu.app  (automatic)


================================================================================
  STEP 1 — DNS (domain registrar ma set karo)
================================================================================

Where you bought kaamsetu.app (GoDaddy, Namecheap, Cloudflare, etc.):

  A) Frontend — Vercel
     Type:  A
     Name:  @   (or blank)
     Value: 76.76.21.21

     Type:  CNAME
     Name:  www
     Value: cname.vercel-dns.com

  B) Backend — Render
     Type:  CNAME
     Name:  api
     Value: kaamsetu-api.onrender.com
     (Replace with your actual Render service hostname after deploy)

DNS propagate thay (5 min – 48 hours).


================================================================================
  STEP 2 — Vercel (frontend → kaamsetu.app)
================================================================================

1) https://vercel.com → your project (frontend)
2) Settings → Domains → Add:
     kaamsetu.app
     www.kaamsetu.app
3) Settings → Environment Variables (Production):
     VITE_API_URL = https://api.kaamsetu.app/api
4) Deployments → Redeploy latest

CLI (optional):
  cd F:\KaamSetu\frontend
  npx vercel domains add kaamsetu.app
  npx vercel domains add www.kaamsetu.app
  npx vercel deploy --prod --yes


================================================================================
  STEP 3 — Render (backend → api.kaamsetu.app)
================================================================================

1) https://render.com → Web Service: kaamsetu-api
2) Settings → Custom Domains → Add: api.kaamsetu.app
3) Environment variables:

   ALLOWED_HOSTS=api.kaamsetu.app,.onrender.com
   FRONTEND_URL=https://kaamsetu.app
   PUBLIC_FRONTEND_URL=https://kaamsetu.app
   CORS_ALLOWED_ORIGINS=https://kaamsetu.app,https://www.kaamsetu.app
   CSRF_TRUSTED_ORIGINS=https://kaamsetu.app,https://www.kaamsetu.app
   DEBUG=False
   (+ email SMTP vars from .env)

4) Manual Deploy after env changes
